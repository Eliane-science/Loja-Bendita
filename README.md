## 📖 Sobre o projeto

O **Bendita Kids - Home & Decor** é um projeto de desenvolvimento **front-end** que simula a vitrine online da loja Bendita Kids. Ele foi pensado para apresentar os produtos de forma atrativa, facilitar o **contato com o cliente** e oferecer uma **navegação simples e agradável**.

Criei o projeto para colocar em prática o que venho aprendendo nos cursos de programação web e ganhar experiência na construção de interfaces reais. Ele segue em evolução: estou estudando a **integração com banco de dados**, para que a loja possa, no futuro, armazenar e gerenciar produtos e pedidos de forma dinâmica.


## ✨ Funcionalidades

- Layout responsivo, adaptado para celular, tablet e computador.
- [Vitrine / catálogo de produtos]
- [Menu de navegação]
- [Criando outras funcionalidades]

## 🛠️ Tecnologias utilizadas

- **HTML5**: estrutura das páginas.
- **CSS3**: estilização e identidade visual.
- **Bootstrap 5**: layout responsivo e componentes.


## 🎯 Aprendizados

Este projeto tem me ajudado a praticar HTML semântico, responsividade com Bootstrap, organização de código e a pensar na experiência de quem utilizará o site.
